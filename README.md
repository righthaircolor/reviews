# Отзывы по брендам

Инструмент для стратега: собирает отзывы о брендах из открытых источников в одну базу
и показывает их в веб-интерфейсе с фильтрами, сравнением и выгрузкой в Excel.

## Источники

| Источник | Что нужно | Ограничения |
|---|---|---|
| App Store | страна + id приложения (или поиск по названию) | около 500 последних отзывов на страну |
| Google Play | id приложения (или поиск по названию) | делит отзывы по языку, а не по стране; лимит задаётся в `brands.yml` |
| Любая ссылка | адрес страницы с отзывами | работает, если на странице есть разметка отзывов schema.org; для остальных страниц нужен ключ ИИ (см. ниже) |

App Store делит отзывы по странам: `by`, `ru`, `us` собираются и сравниваются отдельно.
Google Play делит их по языку: Беларусь и Россия приходят одним русскоязычным потоком («язык RU»).
Имена авторов не сохраняются.

## Первый запуск (один раз)

1. **Settings → Pages** → Source: *Deploy from a branch* → ветка `main`, папка `/docs` → Save.
   Через минуту интерфейс откроется по адресу `https://righthaircolor.github.io/reviews/`.
2. **Actions** → «Сбор отзывов» → **Run workflow**. Если вкладка просит включить Actions — включите.

## Как добавить бренд

Откройте `brands.yml`, нажмите карандаш, добавьте бренд по образцу и сохраните (Commit changes).
Сбор запустится сам; ещё он идёт каждый понедельник. Новые отзывы добавляются к базе, дубли отсеиваются.

Результат каждого запуска виден внизу интерфейса в «Журнале последнего сбора»:
сколько отзывов пришло из каждого источника и где была ошибка.

## Страницы без разметки (необязательно)

Чтобы извлекатель по ссылке работал на любых страницах, добавьте ключ Anthropic API:
**Settings → Secrets and variables → Actions → New repository secret**, имя `ANTHROPIC_API_KEY`.
Запросы к API платные. Сайты с защитой от ботов (Ozon, Wildberries, Amazon) с серверов GitHub обычно не отдаются.

## Запуск на своём компьютере

```
pip install -r requirements.txt
python -m collector
python -m http.server -d docs 8000   # интерфейс: http://localhost:8000
```

Собирайте только общедоступные отзывы и соблюдайте правила площадок.
