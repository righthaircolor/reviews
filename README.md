# Отзывы по брендам

Инструмент для стратега: собирает отзывы о брендах из открытых источников в одну базу
и показывает их в веб-интерфейсе с фильтрами, сравнением и выгрузкой в Excel.

## Источники

| Рынок | Источник | Как подключается | Сколько отдаёт |
|---|---|---|---|
| любой | App Store | сам, по стране из `markets` | около 500 последних на страну |
| любой | Google Play | сам, по языку страны | лимит в `brands.yml` |
| Россия | RuStore | сам, если указан `google_play_id` | лимит в `brands.yml` |
| Беларусь | Onliner (каталог товаров) | сам, поиском по названию бренда | все отзывы на найденные товары |
| Россия и др. | 2ГИС | вручную: ссылки на филиалы | все отзывы филиала |
| Россия, Беларусь и др. | Яндекс Карты | вручную: ссылки на организации | около 50 на организацию |
| любой | Любая страница | вручную: ссылка в `urls` | что есть на странице |

App Store делит отзывы по странам: `by`, `ru`, `us` собираются и сравниваются отдельно.
Google Play делит их по языку: Беларусь и Россия приходят одним русскоязычным потоком («язык RU»).
Имена авторов не сохраняются.

**Только при запуске с компьютера** (серверам GitHub эти площадки отвечают отказом):

| Рынок | Источник | Как подключается |
|---|---|---|
| Россия, Беларусь | Wildberries | сам, поиском товаров бренда |
| глобальный | Trustpilot | вручную: домен компании в поле `trustpilot` |

**Пока не подключены:** Ozon, Яндекс Маркет, iRecommend, Reddit, TripAdvisor — им нужен настоящий
браузер или платный прокси-сервис. Google Maps отдаёт отзывы только через платный API
и не больше 5 на точку.

## Первый запуск (один раз)

1. **Settings → Pages** → Source: *Deploy from a branch* → ветка `main`, папка `/docs` → Save.
   Через минуту интерфейс откроется по адресу `https://righthaircolor.github.io/reviews/`.
2. **Actions** → «Сбор отзывов» → **Run workflow**. Если вкладка просит включить Actions — включите.

## Как добавить бренд

Откройте `brands.yml`, нажмите карандаш, добавьте бренд по образцу и сохраните (Commit changes).
Сбор запустится сам; ещё он идёт каждый понедельник. Новые отзывы добавляются к базе, дубли отсеиваются.

Результат каждого запуска виден внизу интерфейса в «Журнале последнего сбора»:
сколько отзывов пришло из каждого источника и где была ошибка.

## Страницы без разметки (необязательно)

Чтобы извлекатель по ссылке работал на любых страницах, добавьте ключ Anthropic API:
**Settings → Secrets and variables → Actions → New repository secret**, имя `ANTHROPIC_API_KEY`.
Запросы к API платные. Сайты с защитой от ботов (Ozon, Wildberries, Amazon) с серверов GitHub обычно не отдаются.

## Запуск с компьютера

Нужен для Wildberries и Trustpilot. Собирает все источники сразу и отправляет данные на сайт.

Один раз:
1. Установите [Python](https://www.python.org/downloads/) и [GitHub Desktop](https://desktop.github.com/).
2. В GitHub Desktop: File → Clone repository → `righthaircolor/reviews`.

Каждый раз: откройте папку репозитория и дважды щёлкните `run_local.command` (Mac)
или `run_local.bat` (Windows). В конце появится «Готово».

Посмотреть интерфейс без отправки: `python -m http.server -d docs 8000` → http://localhost:8000

Собирайте только общедоступные отзывы и соблюдайте правила площадок.
